### 订单累计成交量

[`TraderMocker::match_once`](../../src/TraderMocker/TraderMocker.cpp) 对剩余量和累计已成交量都做减法。前者正确，后者从 0 变为负数。最终持仓守恒不能替代订单字段正确性验收。

### 日期字段

模拟模块调用 `setOrderTime` 和 `setTradeTime`，没有补相应日期；setter 本身也不自动补日期。不能用 date=0 的流水直接做交易日归档。

### 状态快照

[`CtaStraBaseCtx`](../../src/WtCore/CtaStraBaseCtx.cpp) 中改仓后的保存早于 `on_tick` 的资金浮盈汇总与信号删除。后续内存更新不一定再次保存。这能解释落盘滞后，但本次没有抓取最终运行内存，不扩大结论为“最终内存浮盈必然错误”。

### 退出生命周期

[`WtCtaEngine`](../../src/WtCore/WtCtaEngine.cpp) 析构直接删除 ticker；[`WtCtaRtTicker`](../../src/WtCore/WtCtaTicker.h) 析构为空，可连接线程没有先 stop/join，与 Runner 堆栈相符。

QuoteFactory 缺少完整 shutdown；ParserUDP release 为空，异步 writer 与 caster 的退出也需要核查。错误支持后台任务与对象释放顺序的问题，具体中台崩溃点尚需 Debug/GDB/ASan 确认。

这些处理解决了实验装配与输入问题，没有修复 SIM-01 至 SIM-05 的产品代码。

## 模拟器能力边界

- `queryAccount()` 资金字段固定为 0，不能据此判定交易盈亏。毛盈亏需从成交流水重算，未建模真实手续费和保证金。
- 当前读取 `span`，撮合循环仍硬编码 5ms；配置与实现不一致，待修复和计时验证。
- 相同价格路径的两次基线实际成交价不同，体现当前异步模拟的可重复性限制。
- 多订单共享盘口量、撤单冻结边界、断网重连与压力性能仍未完成验证。
